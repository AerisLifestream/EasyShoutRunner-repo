# EasyShoutRunner

Dalamud plugin for FFXIV. Automatically travels world to world (via Lifestream) and shouts your message at each capital city, then moves on.

This plugin was built with AI assistance.

## Install

1. In-game, open `/xlsettings` → **Experimental** tab → **Custom Plugin Repositories**
2. Add this URL:
   ```
   https://raw.githubusercontent.com/AerisLifestream/EasyShoutRunner-repo/main/pluginmaster.json
   ```
3. Save, then find **EasyShoutRunner** in `/xlplugins` and install.

## Requirements

- [Lifestream](https://github.com/NightmareXIV/MyDalamudPlugins) plugin installed and enabled (used for world travel).

## Usage

- `/esr` — opens the main window
- `/esr start` — starts the run
- `/esr stop` — stops the run
- `/esr config` — opens settings (message, worlds, capitals, delays)

## Disclaimer

Automating actions in-game (including via third-party plugins) is not officially supported by Square Enix. Use at your own risk.
